## Installation

1. Download the `.dmg` for your version above
2. Open the DMG — drag **רמב"ם יומי** to `/Applications`
3. Launch from Applications or Spotlight (`⌘Space` → "רמב"ם")
4. The app lives in the **menu bar** (top-right of screen)

> DMG is unsigned (personal use). If macOS blocks it: right-click → Open → Open anyway.
